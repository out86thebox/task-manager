# My Task Manager

## Project Description

My Task Manager is a beginner-friendly web application built using HTML, CSS, and JavaScript as part of my software engineering bootcamp.

The application helps users organize their daily tasks.

## Features

- Add new tasks
- View tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using browser localStorage

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## How to Use

1. Open the Task Manager website.
2. Type a task in the input field.
3. Click Add Task or press Enter.
4. Use the checkbox to mark a task as completed.
5. Click Delete to remove a task.

Tasks are saved in the browser and remain available after refreshing the page.
